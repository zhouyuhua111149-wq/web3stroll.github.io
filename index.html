从 Web2 到 Web3：不是替代，而是一场关于“数字主权”的进化

在讨论 Web3 之前，我们必须对 Web2 表达敬意。过去二十年里，Web2 为我们提供了极其便利的基础设施。然而，在繁荣背后，我们也发现：作为用户，我们产生的价值往往掌握在中心化公司手中。

什么是 Web3？

Web3 并不是要摧毁 Web2。相反，它是在 Web2 的基础上，通过去中心化协议，让普通用户能够从数据的消耗者，转变为网络的 共同拥有者。

  • Web 1.0 (只读)： 信息单向传递。
  • Web 2.0 (读写)： 社交媒体与互动。
  • Web 3.0 (读、写、拥有)： 数据所有权回归个体。
